# Print sample from truncated distribution

Special printing methods for trunc\_\* classes.

## Usage

``` r
# S3 method for class 'trunc'
print(x, details = FALSE, ...)
```

## Arguments

- x:

  object to print

- details:

  if `FALSE` (default), hides the attributes of `x`

- ...:

  other arguments passed to
  [`base::print.default()`](https://rdrr.io/r/base/print.default.html)

## Value

`x` with or without its attributes
